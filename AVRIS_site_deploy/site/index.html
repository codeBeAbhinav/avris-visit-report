The path

Four steps, in this order

Every report follows the same path. The tool shows only the steps that fit the visit you chose.

  1. Set up once on your device

    Open the tool in Chrome, Edge or Safari and enter your name. Your name is filled in as Prepared by on every new report.

  2. Choose the visit type

    Full site survey, Follow-up visit or Quick enquiry. The choice decides which steps and which required items you see.

  3. Fill in the visit

    Work through the steps on site. Everything saves as you type, so you can stop and return later.

  4. Check, then Generate

    The last screen lists anything still missing. When every required item is done, the Generate report button appears. Tap it to lock the report and prepare the PDF, Word and CSV files.

Step 2 in detail

Which visit type should I choose?

Pick the one that matches the visit. You can change the type on the first step of a report if you chose wrongly.

Visit typeUse it forSteps
Full site surveyA first visit to a new site. Records people met, site and waste details, space and route, photos and the recommendation.11
Follow-up visitA return visit to a site already surveyed. Records what changed, new photos and the next step. Waste per day is optional.7
Quick enquiryA short visit or call to size up a lead. Records basics, site scale and waste per day only.6

Every type ends with the same Check and generate screen. The report layout and numbering are the same for all types. The visit type is printed on page 1 for Follow-up visit and Quick enquiry.

Read this first

Before you start

The tool shows the same list on screen before it starts. These points protect your reports.

Do
  • Fill in the steps in order. Everything saves as you type.
  • Check the customer name, date and kg per day before you generate.
  • Tap Generate report only when the visit is finished. You can reopen it later.
  • Be online when you tap Generate if Google Drive is connected.
  • Download a backup from Settings now and then.
Do not
  • Do not clear this site's data or cookies in the browser. Reports are stored there and would be lost.
  • Do not use a private or incognito window. Reports vanish when it closes.
  • Do not open the tool inside a chat app or preview. Use Chrome, Edge or Safari.
  • Do not close the page while it says Saving to Google Drive.
  • Do not share the Google Drive web link or access key.
Step 1 in detail

First-time setup

Each phone or computer needs this once. Reports are stored per device and per web address, so always use the same address.

On your own device

  1. Open the AVRIS web address in Chrome, Edge or Safari, in a normal window.
  2. Read the Before you start screen and tap I understand, start the tool. The tool starts only after this.
  3. Enter your name and tap Continue. The first start takes a few seconds.
  4. Optional on a phone: use the browser menu and choose Add to Home Screen, so the tool opens like an app.

Connect Google Drive (optional)

With Drive connected, every generated report gets the next number and is filed in Drive and in the register Sheet. Without it, reports are numbered on this device only.

The administrator does the script set-up once. A surveyor then only needs the two items it produces: the Web app URL (ends in /exec) and the access key.

  1. In the tool, tap your name on Home to open Settings.
  2. Under Google Drive, paste the Web app URL and the access key.
  3. Tap Save and test. You should see Connected to Google Drive.

Administrator set-up: create the script from the supplied code file, run setup once and allow permissions, then Deploy as a Web app with Execute as Me and Who has access set to Anyone. The full steps are in the Drive set-up guide that comes with the code file.

Step 4 in detail

What Generate does

Generate appears only on the last screen, after every required item is done.

  1. It locks the report and moves it to Completed. You can reopen it later to edit and generate again.
  2. It prepares the PDF, Word and CSV files, which you download on the next screen.
  3. With Drive connected, it issues the next report number, for example Avris/CHUGG/S.A/014/26-27. The count restarts at 001 on 1 April.
  4. With Drive connected, it files the PDF, Word file, CSV, photos and a restorable data file in a folder for that report, and adds one row to the register Sheet.

Drafts show --- as the number until you generate. If Drive is connected and you are offline, Generate waits until you are online, so no number is wasted. If a Drive upload fails after the number is issued, the report shows a Retry button and the tool retries by itself when you are back online.

Help

If something looks wrong

Open the question that matches what you see.

I cannot see the Generate report button

Generate is hidden until the visit is complete. Open the last screen, Check and generate. It lists every item still needed. Fix those, and the button appears at the bottom of the screen.

My reports are missing

Reports live in the browser on the device where you made them. They do not follow you to another phone, another browser or another web address. Check that you are on the same device, the same browser and the same address.

If you cleared site data or used a private window, the reports on that device are gone. Restore from a backup file: Settings, then Restore from backup.

How do I move reports to another device?

On the old device open Settings and tap Download backup. Send the file to the new device, open Settings there and choose Restore from backup. With Drive connected, each generated report also has a report data.json file in its Drive folder, which Restore accepts.

Google Drive says it could not answer or save

In Settings, under Google Drive, tap Save and test. The tool shows the likely cause. The usual ones are:

  • Who has access is not set to Anyone on the web app. Set it to Anyone, make a New version and deploy.
  • The URL pasted is a Library URL. Copy the Web app URL that ends in /exec.
  • The script permissions were never allowed. Run setup once in the script editor and allow access.
  • The access key is wrong or still reads the placeholder. Copy the whole ACCESS_KEY value from the script.
  • A browser extension or network filter blocks Google. Try Chrome in a normal window with extensions off.
The tool does not start, or shows STOP on the checks

Open the tool in Chrome, Edge or Safari in a normal window. Chat apps, social apps and preview panes often block storage or WebAssembly, which the tool needs. Open the same address in the browser app itself.

Can I see the warnings again?

Yes. In the tool open Settings and choose Show the warnings again. They also reappear every 14 days.
